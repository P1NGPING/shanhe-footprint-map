# 山河足迹

中国行政区旅行地图，支持多图层、集合运算、好友足迹对比，以及城市照片、随笔和评论。原作者：Cloudchaser_dyq。

## 一、我想直接使用

### 打开网站

**[立即使用山河足迹 →](https://cloudchaser-city-atlas.lagrangejr.chatgpt.site/)**

用电脑或手机浏览器打开即可，无需下载源码、安装 Node.js 或执行构建命令。把这个链接发给朋友，他们也可以直接使用。

### 账号与常用操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 先试试地图 | 直接点击城市、添加图层；未登录的地图保存在当前浏览器。 |
| 保存到自己的账号 | 点击右上角「登录 / 创建账号」，设置本站用户名和密码，保存注册时显示的恢复码。登录后地图会自动同步。 |
| 使用多个图层 | 选择图层，再点击城市加入或移出。一个城市可以属于多个图层，重叠区域以条纹显示。 |
| 区分去过与想去 | 在图层设置中选择是否「计入去过」。想去、途经或其他主题可以单独建层。 |
| 查看交集与并集 | 打开「集合」，选择两个图层和运算方式；结果可以保存为新图层。支持交集、并集、差集、对称差、补集及两者之外。 |
| 与朋友比较足迹 | 在「好友」页交换好友 ID，发送并确认申请。选择 1～3 位好友，可以查看单个好友去过的地方，也可以比较所有人的共同足迹、去过的合集和都未去过的地方。 |
| 分享照片与随笔 | 切换「照片随笔」，按省份选择城市，也可搜索或从最近选择进入。每条记录最多 3 张照片，发布前可预览和逐张移除，可选「公开」或「好友可见」。登录用户可以评论自己有权查看的记录。 |

拖拽地图可以平移，滚轮可以缩放，右侧复位按钮恢复全国视图。右键城市可将其移出当前图层；背景颜色可以自行设置。

本站账号独立注册，不需要微信或 ChatGPT 账号。忘记密码时，可以用注册时保存的恢复码重设密码。

### 导入旧地图与备份

1. 在旧版 HTML 页面中导出配色 JSON。
2. 打开新版网站并登录，进入「图层 → 导入、备份与导出 → 导入 JSON」。
3. 选择旧文件。旧版每种颜色会转成独立图层，保留颜色备注和显示状态；导入会替换当前图层，可以撤销。
4. 检查各图层是否应「计入去过」，避免把想去的地方计入好友足迹比较。

随时可以导出图层 JSON 备份，或导出 SVG / PNG 地图。**图层 JSON 只备份地图，不包含照片、随笔、好友关系和评论。**

未登录的草稿保存在当前浏览器；首次创建空账号时，会带入当前访客地图。已有账号优先加载自己的云端记录。多台设备同时修改时，网站会让你选择保留本机版本或加载云端版本，也可以先导出本机备份。

## 二、我想运行或开发源码

### 本地运行

当前本地服务器使用 **Node.js 24 或更高版本**。安装后，在终端执行：

```sh
git clone https://github.com/Cloudchaser-dyq/shanhe-footprint-map.git
cd shanhe-footprint-map
node scripts/dev-server.mjs
```

已经下载源码的话，只需在项目目录执行最后一行。然后打开 **http://127.0.0.1:4317**。在终端按 `Ctrl+C` 停止服务。

本地运行只使用 Node.js 内置模块，**无需先安装 pnpm 或项目依赖，也无需先测试、构建**。修改 `web/` 下的文件后，刷新浏览器即可查看；修改服务端代码后需重启服务。

本地是独立副本，账号、数据库和照片与线上网站分开。数据保存在 `.task-tmp/local-data/`，请保留或备份这个目录。服务仅监听本机，朋友共享足迹应使用线上网站。

### 项目结构与技术选型

| 路径 | 用途 |
| --- | --- |
| `web/` | 原生 HTML、CSS、JavaScript 界面、图层计算和地图数据 |
| `worker/api.mjs` | 图层、好友、照片、随笔和评论接口 |
| `worker/auth.mjs` | 本站账号、会话、密码与恢复码 |
| `worker/index.mjs` | Cloudflare Worker 生产入口 |
| `scripts/dev-server.mjs` | Node.js 本地服务，使用 SQLite 和磁盘文件 |
| `scripts/build.mjs` | 将网页资源与后端打包为生产 Worker |
| `db/`、`drizzle/`、`migrations/` | 数据库结构与迁移 |
| `tests/` | 集合运算、数据迁移、账号、权限和 HTTP 测试 |

访问网站只需浏览器；当前源码在本机运行、构建时使用 Node.js；线上后端运行在 Cloudflare Workers。若改用 Python、Java 等后端，需要重新实现或适配现有接口与存储层。

### 测试

修改代码后，可按需运行自动测试：

```sh
node --test tests/*.test.mjs
```

测试覆盖集合运算、旧版迁移、身份验证、好友及照片权限、多设备冲突、分页与真实 HTTP 持久化。HTTP 测试需要允许本机回环连接。

### 构建与部署

准备部署或修改数据库结构时，再安装 pnpm 和构建依赖：

```sh
pnpm install --frozen-lockfile
pnpm build
```

输出为 `dist/server/index.js`，包含网页、脚本、样式和地图数据。构建只生成部署文件，不会自动发布网站。

线上版本需要两个 Cloudflare 存储绑定：

| 绑定 | 存储内容 |
| --- | --- |
| D1：`DB` | 账号、会话、图层、好友关系、随笔与评论 |
| R2：`BUCKET` | 照片，通过后端接口检查访问权限 |

本仓库的 `.openai/hosting.json` 对应当前 Sites 项目。自行部署时，请使用自己的托管项目和存储配置，并应用数据库迁移。账号、同步、上传和评论需要后端运行，单独部署到 GitHub Pages 这类静态托管服务无法提供这些功能。

修改数据库结构时，编辑 `db/schema.js`，执行 `pnpm db:generate` 生成迁移。生产迁移位于 `drizzle/`，本地迁移位于 `migrations/`；两者应保持一致，已应用的迁移应保留并追加新迁移。

### 升级后继续使用原账号

更新现有网站时沿用原站点、数据库和照片存储。用户继续使用原账号、密码和好友 ID，原有足迹、好友关系、照片与随笔也继续保留。普通功能升级不重置账号、不要求重新注册，也不主动撤销仍有效的登录会话。

`tests/account-upgrade.test.mjs` 用固定的历史合成账号验证新增迁移后的原密码、原会话与原身份兼容性。标准构建会先执行这项检查，失败则停止构建；完整发布前仍需运行全部测试。维护约定见 `AGENTS.md`。

登录会话正常到期后，用户用原账号和密码重新登录即可，无需创建新账号。

### 数据与安全说明

- 密码使用带随机盐的 PBKDF2-SHA256 派生值；会话和恢复码仅保存摘要。生产会话 Cookie 使用 Secure、HttpOnly、SameSite=Lax。
- 重设密码会撤销旧会话，并生成新的恢复码。
- 个人地图、数据库、照片和环境变量文件不提交到 GitHub；请保留 `.gitignore` 中的排除规则。
- 地图边界来自阿里云 DataV GeoAtlas。`scripts/prepare-map.mjs` 可以重新生成数据；仓库已包含地图，日常运行无需重新下载。
- 当前地图包含 370 个可选行政区及 35 条省区、辅助边界。除地级行政区外，也包含省、自治区直辖市县及林区，补齐海南、湖北、河南和新疆的原有空白。直辖市、港澳台按整体处理，辅助边界不计入可选区域。已有行政代码和边界保持不变，原有足迹继续保留。
